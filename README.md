AdVision
AdVision is an intelligent, vision-based advertisement system designed to deliver personalized content through real-time facial recognition. The name combines “Ad” (Advertisement) and “Vision” (Computer Vision), reflecting the system’s purpose of enhancing marketing strategies using demographic analysis.

Overview
AdVision automatically detects and recognizes faces from a live video feed and extracts demographic attributes such as gender and age. Based on these attributes, the system recommends and displays the most relevant advertisement to the viewer.

This solution aims to improve advertising effectiveness and audience engagement by tailoring content in real-time according to the user’s profile.

Technology Stack
Backend: Python (Flask)

Frontend: HTML, CSS, JavaScript

Machine Learning Models:

Gender Prediction: Support Vector Machine (SVM)

Age Prediction: Convolutional Neural Network (CNN)

Both models are trained on extensive datasets and provide reliable performance with high accuracy in real-time applications.

Features
Real-time face detection and demographic analysis

Gender and age prediction with machine learning

Dynamic advertisement selection based on user profile

Integration of computer vision and web technologies

Applications
Interactive advertisement displays in malls and retail environments

Targeted content delivery at promotional and public events

Third-party integration for context-aware digital advertising platforms
